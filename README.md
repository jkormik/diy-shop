# Handmade Soul - Интернет-магазин ручной работы

Эстетичный интернет-магазин для продажи изделий ручной работы (вышивка, декор, аксессуары).

## Стек технологий
- **Backend:** Python 3.11+, Django 4.2
- **Database:** SQLite (для разработки), PostgreSQL (для продакшена)
- **Frontend:** HTML5, Tailwind CSS
- **Images:** Pillow

## Функционал
- [ ] Главная страница с категориями и витриной
- [ ] Каталог товаров с фильтрацией
- [ ] Поиск с расширенными фильтрами (категория, цена, цвет)
- [ ] Корзина покупок
- [ ] Список избранного
- [ ] Страницы «Контакты» и «Условия»
- [ ] Панель администратора для управления товарами

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd diy-shop
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # venv\Scripts\activate   # Для Windows
   pip install -r requirements.txt
   ```

3. Примените миграции:
   ```bash
   python manage.py migrate
   ```

4. Запустите сервер:
   ```bash
   python manage.py runserver
   ```

## Структура проекта
- `core/` — основные настройки проекта.
- `shop/` — приложение магазина (модели, логика, шаблоны).
- `static/` — статические файлы (CSS, JS).
- `media/` — загруженные изображения товаров.
